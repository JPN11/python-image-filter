# python-image-filter

# Usage

To apply a filter to an image, use the following command:

```
python main.py <flag> <image>
```

## Available Flags:
- `-g`: Grey filter
- `-s`: Sharpen filter
- `-r`: Reflect filter
- `-i`: Invert filter
- `-b`: Blur filter
- `-e`: Emboss filter
- `-c`: Contour filter
- `-d`: Detail filter
- `-ed`: Edge filter

## Example:
To apply a grey filter to an image named `python.jpg`, use:
```
python main.py -g filter/images/python.jpg
```
